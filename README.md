# PortfolioWebsite

Quantitative Trading & Data Science Portfolio Website for **Tengku ANAS**.

Featured aesthetic inspired by luxury Manhattan institutional finance and American Psycho executive cardstock typography.

## Tech Stack
- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 + Custom Vanilla CSS Design Tokens
- **Typography**: Cormorant Garamond / Small-Caps Roman Executive Serif
- **Features**: Interactive Quant Model Inspection, Portfolio Matrix, Digital vCard Exporter

## Setup & Local Development
```bash
npm install
npm run dev
```

## Build & Production
```bash
npm run build
```
